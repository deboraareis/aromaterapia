Este é um arquivo de **exemplo** (o nome começa com `_`, então o `build.py` o ignora).

Para publicar um artigo novo:

1. Copie este arquivo para `content/blog/meu-novo-artigo.md` (sem o `_` no início).
2. Preencha o front-matter (título, slug, data, resumo, capa).
3. Escreva o corpo em Markdown normal — títulos com `##`, links, listas, etc.
4. Rode `uv run python build.py`.
